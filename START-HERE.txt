POLE INSIGHTS - P28
Based on Carl Rathbone's Pole Laboratory P26
Updated 8 October 2026

RUN LOCALLY
1. Install Node.js 22.13 or newer.
2. Open PowerShell in this repository directory.
3. Run:
     npm ci
     npm run dev
4. Open the URL printed by Vite (normally http://127.0.0.1:5190/).
   Keep the terminal open; another port may be selected if occupied.

On Windows, Start-Pole-Lab.ps1 performs the same launch. In the complete local
handoff, the workspace-level START-WINDOWS.cmd also launches this DEV source.

The interface must show "Pole Insights"; About identifies P28.

Do not open index.html directly. Calculations use web workers and require the
local HTTP server. Local startup does not publish or deploy the application.

TEST AND BUILD
  npm test
  npm run build

The checked build runs the inherited P01-P26 verification chain, the P27
requirement checks, integration checks and Vite build. Output is dist\.

BRANCHES
- main: original P26 baseline.
- dev: Pole Insights P28 development; production Pages tracks dev.

CLOUDFLARE
Hosted application: https://pole-insights.pages.dev/
Production and preview use separate Access applications and AUD settings.
Read docs\DEPLOYMENT.md before changing deployment or Access configuration.
OAuth credentials belong in ignored .env.local locally and Cloudflare Secret
variables in production, never in browser code or source handoffs.

MODEL SCOPE
Pole Insights remains an illustrative prototype, not an engineering-qualified
design tool, fracture prediction, measured UB1000 interpretation or climbing
clearance. Historical P26 films and records retain their original names.
