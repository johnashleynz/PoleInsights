# About this model

This project originates from Carl Rathbone's Pole Laboratory, version P26.

P27 delivered the original requirements enhancement set. The current `dev` work is
P28: integrations, recorded measurements and shared asset identity, preserving the
P26 baseline for comparison and review. See P28-CHANGELOG.md and
P28-AS-BUILT-REQUIREMENTS.md. Structural qualification limits remain unchanged.
