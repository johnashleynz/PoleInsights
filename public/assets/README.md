# Reserved public visual assets

This folder will contain assets deliberately approved for delivery to website visitors: logo, fonts, wood materials, probe models and lesson imagery. No third-party assets have been copied here at P00.

Record source, licence/permission, author, intended use and file revision for each asset. Optimised versions must preserve the approved appearance. Generated or representative imagery must not be described as an actual inspected pole, instrument output or decay scan.

Keep sawn-face appearance spatially consistent with the pole and defects. Public assets must never contain private calibration datasets or credentials.
